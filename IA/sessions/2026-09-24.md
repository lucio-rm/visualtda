## 2. Implemented Features & Technical Details

### A. 7-Stage Pedagogical Progression Model (`src/context/StudentProgressContext.tsx`)
- Formalized student progression into 7 discrete educational states:
  - `unseen`: Exercise has not yet been opened.
  - `exploring`: Student entered Phase 1 (Discover) and interacted with the playground.
  - `attempted`: Student began writing code in Phase 2 (Solve).
  - `testing`: Student executed tests in Python via Pyodide and received failure diagnostics.
  - `passed`: Student passed 100% of the unit tests in Phase 2, unlocking Phase 3.
  - `completed`: Student reviewed the canonical solution and formal correctness theory in Phase 3.
  - `instructor`: Demonstration mode for classroom projection, bypassing scaffolding without setting permanent completion marks.
- Implemented **monotonic rank invariant** (`rank(unseen)=0 < rank(exploring)=1 < ... < rank(completed)=5`), guaranteeing that visiting Phase 1 or re-running tests never downgrades a higher achievement.
- Added visual status badges and dynamic CTA buttons to `ExerciseCard.tsx`.
- Automated tests added in `tests/studentProgress.test.tsx` (5/5 PASS).
- Formal architectural documentation added to `docs/learning-progress-model.md`.

### B. Complete Visualizer & Playground Implementations (All 9 Remaining Exercises)
All registered in `src/engine/exerciseViewRegistry.tsx`:
1. **`interval-partitioning-greedy` (Chapter 4.1)**:
   - `intervalPartitioningTrace.ts`: Generates step-by-step room allocation using a min-heap of finish times and computes theoretical depth $d$.
   - `IntervalPartitioningVisualizer.tsx`: 2D timeline SVG chart displaying classroom lanes and time markers.
   - `IntervalPartitioningPlayground.tsx`: Interactive lecture schedule builder with real-time conflict detection and depth invariant validation.
2. **`minimize-lateness-greedy` (Chapter 4.2)**:
   - `minimizeLatenessTrace.ts`: Earliest Deadline First (EDF) scheduler calculating max lateness $L = \max(0, f_i - d_i)$.
   - `MinimizeLatenessVisualizer.tsx`: Single timeline bar with colored job blocks, deadline pin markers, and red lateness brackets.
   - `MinimizeLatenessPlayground.tsx`: Interactive job permutation tool demonstrating the Exchange Argument and inversion counting.
3. **`karatsuba-dyc` (Chapter 5.5)**:
   - `karatsubaTrace.ts`: Decomposes large integers $x$ and $y$ into $x_1, x_0, y_1, y_0$ and traces the 3 multiplications ($z_2, z_0, z_{sum}$).
   - `KaratsubaVisualizer.tsx`: 2D SVG tree diagram demonstrating how the algebraic identity eliminates the 4th multiplication.
   - `KaratsubaPlayground.tsx`: Custom integer multiplier allowing students to test custom inputs and verify against standard multiplication.
4. **`majority-element-dyc`**:
   - `majorityElementTrace.ts`: Divide-and-conquer recurrence $T(n) = 2T(n/2) + O(n)$ comparing candidate occurrences.
   - `MajorityElementVisualizer.tsx`: Subarray range selector, mid divider, candidate frequency meters, and threshold check ($> n/2$).
   - `MajorityElementPlayground.tsx`: Interactive array editor with frequency table and edge-case presets (exact $n/2$, all distinct).
5. **`median-of-medians-dyc`**:
   - `medianOfMediansTrace.ts`: Deterministic $O(n)$ selection algorithm with groups of 5 and recursive median of medians pivot $p$.
   - `MedianOfMediansVisualizer.tsx`: 2D SVG matrix of 5-element groups, median row highlight, and $\ge 30\%$ pruning guarantee.
   - `MedianOfMediansPlayground.tsx`: Interactive $k$-th element selector comparing groups of 5 ($O(n)$) vs groups of 3 ($O(n \log n)$).
6. **`segmented-least-squares-dp` (Chapter 6.3)**:
   - `segmentedLeastSquaresTrace.ts`: Computes squared error $e_{i,j}$ and 1D DP recurrence $OPT(j) = \min_i (e_{i,j} + C + OPT(i-1))$.
   - `SegmentedLeastSquaresVisualizer.tsx`: 2D coordinate plane with fitted lines, residual error bars, and DP array table.
   - `SegmentedLeastSquaresPlayground.tsx`: Interactive penalty parameter slider $C$ illustrating the trade-off between overfitting and underfitting.
7. **`rna-secondary-structure-dp` (Chapter 6.5)**:
   - `rnaSecondaryStructureTrace.ts`: Watson-Crick pairing rules {A-U, C-G}, no-crossing condition, and sharp-turn rule ($t < j - 4$).
   - `RnaSecondaryStructureVisualizer.tsx`: Non-crossing arc diagram and upper-triangular 2D DP matrix table $OPT[i, j]$.
   - `RnaSecondaryStructurePlayground.tsx`: Interactive RNA sequence editor verifying biological pairing rules.
8. **`hamiltonian-cycle-backtracking` (Chapter 8)**:
   - `hamiltonianCycleTrace.ts`: Backtracking graph DFS tracking visited vertices and detecting return edge to origin.
   - `HamiltonianCycleVisualizer.tsx`: 2D SVG graph with visited sequence badges and animated edge highlighting.
   - `HamiltonianCyclePlayground.tsx`: Manual vertex navigation tool with dead-end alerts and backtrack undo button.
9. **`tsp-branch-and-bound`**:
   - `tspBranchAndBoundTrace.ts`: Traveling Salesperson Problem with minimum outgoing edge lower bounding.
   - `TspBranchAndBoundVisualizer.tsx`: City map with active tour and Branch & Bound incumbent updates.
   - `TspBranchAndBoundPlayground.tsx`: Interactive tour path builder and lower bound comparison.
