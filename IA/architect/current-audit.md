## 3. Detailed Subsystem Audit Findings

### 3.1 Security Audit
- **Unsafe DOM APIs**: Scanned with `grep -rn "dangerouslySetInnerHTML\|innerHTML\|eval(\|new Function(\|document\.write" src/` — returned **0 occurrences**.
- **Secrets & Credentials**: Zero hardcoded credentials in codebase. Master password for instructor decryption (`MEL75.29`) derives key via client-side PBKDF2 with unique salts.
- **Worker Isolation**: `pyodideWorker.ts` runs off-main-thread with zero access to `window`, `document`, or `localStorage`.
- **Encrypted Canonical Solutions**: Built using AES-256-GCM + PBKDF2 with dual slots (`instructor` and `student`).

### 3.2 Architecture Audit & Decoupling

- **`src/engine/exerciseViewRegistry.tsx`**: Central registry connecting 38 exercises with their visualizers and playgrounds.

- **`src/styles/`**: CSS custom properties with design tokens. Mission V11 migrates hand-picked values to Radix Colors.
